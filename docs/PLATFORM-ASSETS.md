# Ícones das plataformas

Os quatro SVGs foram reaproveitados dos arquivos de plataforma usados na revisão do PromoGames. As silhuetas vêm do catálogo Simple Icons, sem redesenho; o catálogo usa CC0 e as marcas pertencem aos respectivos titulares. Nintendo usa o símbolo do Switch e PC usa Windows, conforme a revisão original.

| Arquivo | Origem registrada na revisão original |
| --- | --- |
| `public/brands/playstation.svg` | https://raw.githubusercontent.com/simple-icons/simple-icons/13.0.0/icons/playstation.svg |
| `public/brands/xbox.svg` | https://raw.githubusercontent.com/simple-icons/simple-icons/11.0.0/icons/xbox.svg |
| `public/brands/nintendoswitch.svg` | https://raw.githubusercontent.com/simple-icons/simple-icons/13.0.0/icons/nintendoswitch.svg |
| `public/brands/windows.svg` | https://raw.githubusercontent.com/simple-icons/simple-icons/11.0.0/icons/windows.svg |

Os ícones usam a cor do tema por máscara CSS. O texto adjacente identifica a plataforma para tecnologias assistivas. Logos de lojas, WhatsApp, Telegram, gift cards e arte de GTA VI não fazem parte desta atualização do JoystickNights.
